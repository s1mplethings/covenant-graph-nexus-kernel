## [0.2.0-rc.3]

- Normalize the public project name to CGNK while retaining the `cgkn` Python
  namespace and legacy machine identifiers for backward compatibility.
- Bind history compliance audits to an explicit Source Closure and reconcile
  prior blob counts as valid measurements of different commit scopes.
- Reject Architecture Router V1 after the ITER-056 paired oracle showed zero
  architecture-only successes and no gain over Direct Cheap.

  provenance metadata.
- Add indexed knowledge retrieval and bounded context packing evidence,
  preregistered 72-task cross-domain evaluation, statistical analysis, and
  clean-clone reproduction material.
- Stabilize downstream project-worker prompts by excluding volatile timing,
  usage, and receipt-only dependency metadata.
- Qualify the CapabilityTree/ExecutionDAG kernel foundation, minimal project
  blueprint generation and repair, localized evidence-grounded Conversation,
  segmented ProjectKnowledgePack persistence, capability routing, bounded
  self-growth experiments, Promotion, Community, and Project Digital Persona
  application capabilities at their documented evidence levels.

  Multi-Agent Runtime as not recommended under current evidence.
