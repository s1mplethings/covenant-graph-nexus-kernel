# CGKN v0.2 summary

v0.2 strengthened the reviewed Provider project-generation mainline,
ProviderJob ownership and bounded concurrency, candidate identity, post-build
verification, Product Design governance, false-pass supervision, repair
routing, `local_packager`, and public delivery gating.

Important failures included Provider transport/quota blocks, incomplete output
contracts, stale evidence, and generated-project surrogate behavior. The
response was fail-closed validation, affected-only repair, explicit provenance,
and strict separation of Provider authorship, CGKN evidence authority, Codex
audit, packaging, and delivery.

Relevant release commits include `c99e545`, `63f2fe2`, and `22cd65a`. Detailed
runtime logs and iteration records remain available in Git history rather than
the current project-management surface.
