# CGKN v0.1 summary

The early kernel established typed contracts, flow compilation, schema and
policy validation, deterministic diagnostics, context packs, conversation
state, and a guarded local packaging boundary.

Important decisions included keeping machine contracts explicit, treating
workflow state separately from evidence status, and preventing planning output
from authorizing delivery. Early failures showed that file existence and prose
reports were insufficient evidence. The detailed iteration records remain in
Git history; current authority is defined by the kernel contract and registry.

Residual risk: some legacy support paths and naming markers remain for backward
compatibility and must not become new formal routes.
