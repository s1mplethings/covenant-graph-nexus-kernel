# Agent + cheap executor MVP

Iteration `ITER-MVP-AGENT-CHEAP-EXECUTOR-006` closed with `PASS` on 2026-10-15.

The increment removed string version ordering and GrowthLoop's executor special
case, then added a provider-backed Agent adapter, a bounded cheap LLM executor,
and a four-decision project loop over the existing CapabilityTree,
ExecutionDAG, Block, ExecutorRegistry, FileRunStore, and CapabilityRegistry
authorities.

Real validation used `qwen3.8-max` for two Agent decisions and
`qwen3.7-flash` for one worker proposal. The worker patched `math_utils.py` and
real pytest changed from failure to `1 passed`. Fake-provider integration also
proved affected-only repair, worker escalation, and forbidden-action rejection.

The direct high-model baseline passed in one call. CGKN used two high-model
checkpoints plus one cheap worker call, so decision efficiency is
`PASS_WITH_LIMITS`: authority separation and observable recovery are proven,
but a call-count advantage is not claimed for this tiny task.
