# CGKN v0.3 summary

v0.3 adds the Artifact-driven Pipeline Kernel as an additive execution lane:
typed `ArtifactInstance` and `ArtifactRef`, local store and index, deterministic
content hashes, provenance, projections and module context budgets,
fingerprints, cache, dependency lineage, stale propagation, partial recompute,
effect cardinality, ref-only checkpoints, and stale-aware delivery judgment.

The Todo refactor reference demonstrates that changing requirement
interpretation recomputes dependent analysis/architecture/plan nodes while an
unchanged project snapshot remains reusable. The reviewed Provider, canonical
evidence, packaging, and delivery authorities are unchanged.

Primary implementation commit: `bc02f96105c71eb9cdb401ad9413c7d4f6b2c046`.
Curated verification is under `evidence/artifact-kernel/v0.3/`. Known limit:
the earlier repository-wide profile contained unrelated baseline failures, so
the scoped result was `PASS_WITH_LIMITS`, not a repository-wide formal PASS.
