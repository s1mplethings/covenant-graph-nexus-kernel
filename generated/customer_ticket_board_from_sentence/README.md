# Local Task Board

Generated by CGNK local runtime executor.

## Goal

给我做一个本地客户工单看板 客服澄清信息： - acceptance: 输出项目蓝图、生成过程、测试图、效果报告，并生成可打开的本地项目。 生成要求：输出真实项目文件、项目蓝图、生成过程、测试图、效果报告和 runtime_result。

## Use

Open `index.html` in a browser. The board stores tasks in browser localStorage.
