# Local Task Board

Generated by CGNK local runtime executor.

## Goal

我要做一个本地任务看板项目：用户从客服入口提出需求，本地 librarian 查找可用模块，本地 agent 规划生成流程，对抗审查后生成项目蓝图、测试图和效果报告，最后可以通过 API 生成内容并通过 Telegram 交付结果

## Use

Open `index.html` in a browser. The board stores tasks in browser localStorage.
