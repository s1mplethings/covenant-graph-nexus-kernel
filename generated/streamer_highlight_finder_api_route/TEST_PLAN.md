# Test Plan for Game Highlight Finder

## Test Cases
1. **Import Data**: Verify that valid JSON data imports correctly and displays highlights.
2. **Score Calculation**: Ensure that the scoring function calculates scores accurately based on the defined logic.
3. **Sorting**: Check that highlights are sorted in descending order based on scores.
4. **Filtering**: Test all filter controls to ensure they filter results correctly based on user input.
5. **Manual Marker Addition**: Confirm that new markers can be added and displayed in the results.
6. **Export Functionality**: Validate that the export button creates a downloadable JSON file with the current highlights.
