# Game Highlight Finder

This project allows users to import game streaming event data, automatically score and sort highlights, filter by streamer, game, category, and score, add manual markers, and export a list of highlights.

## Features
- Import JSON data of streaming events.
- Automatic scoring based on defined criteria.
- Sorting of highlights by score.
- Filtering options for streamer, game, and score.
- Manual marker addition.
- Export highlights to a JSON file.

## Usage
1. Open `index.html` in a web browser.
2. Use the file input to import your JSON data.
3. Apply filters as needed.
4. Add manual markers if desired.
5. Export your highlights using the export button.

## Requirements
- A modern web browser that supports HTML5 and JavaScript.
