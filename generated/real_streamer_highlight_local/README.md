# Streamer Highlight Finder

Generated by CGNK local runtime executor.

## Goal

做一个本地主播高光片段筛选器，支持导入直播事件 JSON，按强度和聊天热度评分排序，按主播、游戏、分类和最低分筛选，支持手动添加标记、导出 JSON、本地保存，并输出测试图和效果报告

## Use

Open `index.html` in a browser. Paste stream event JSON or use the built-in sample data, then click **Analyze highlights**.

## Input Event Shape

```json
{
  "streamer": "NovaCarry",
  "game": "Apex Legends",
  "time": "00:03:42",
  "title": "1v3 clutch",
  "category": "clutch",
  "intensity": 94,
  "chatRate": 182,
  "keywords": ["clutch", "win"],
  "description": "Why this moment matters"
}
```
