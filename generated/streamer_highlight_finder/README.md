# Streamer Highlight Finder

Generated by CGNK local runtime executor.

## Goal

我想要一个可以给我找出游戏主播的高光时刻的项目，可以导入直播事件数据，自动评分和排序，筛选主播、游戏、分类和分数，添加人工标记，导出剪辑清单，并输出测试效果报告

## Use

Open `index.html` in a browser. Paste stream event JSON or use the built-in sample data, then click **Analyze highlights**.

## Input Event Shape

```json
{
  "streamer": "NovaCarry",
  "game": "Apex Legends",
  "time": "00:03:42",
  "title": "1v3 clutch",
  "category": "clutch",
  "intensity": 94,
  "chatRate": 182,
  "keywords": ["clutch", "win"],
  "description": "Why this moment matters"
}
```
