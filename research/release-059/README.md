# ITER-059 evidence index

- `preregistration.md` — frozen question, cases, gates, and interpretation limits.
- `source_closure.json` — exact source commit/tree and schema/policy hashes.
- `formal_evaluation.json` — sanitized formal run evidence.
- `corpus_profile.json` — aggregate non-scale corpus profile.
- `security_audit.json` — current/history and corpus security verdict.
- `release_compliance_audit.json` — complete secret/privacy/history audit output.
- `provenance_audit.json` — license, dependency, benchmark, asset, and Postiz audit.
- `clean_clone_reproduction.json` — isolated installation and smoke verification.
- `regression.json` — collection, full repository, profile, domain, and gate totals.
- `claim_ledger.json` — supported and explicitly unsupported public claims.
- `technical_report.md` — academic-style technical report.
- `evidence_closure.json` — final evidence and release identity.

No real corpus contents, hidden evaluator packets, raw Provider output,
credentials, or restricted benchmark datasets are included in this directory.
