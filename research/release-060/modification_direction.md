# CGNK Modification Direction

Decisions are evidence-bound recommendations; no production default changes are made in ITER-060.

- Direct path → `PROVEN_DIRECTIONALLY` → retain as the simple-project candidate.
- Evidence/state substrate → `NEUTRAL` → retain, simplify, or strengthen only in the next iteration.
- CapabilityTree/ExecutionDAG → `NEUTRAL` → keep optional unless formal HIGH evidence proves necessity.
- Full repair orchestration → `NEUTRAL` → do not promote without repair-heavy benefit.
- Capability reuse → `INSUFFICIENT_EVIDENCE` → design a separate cross-family reuse study before claiming benefit.
