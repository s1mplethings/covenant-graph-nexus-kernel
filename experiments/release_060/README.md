# ITER-060 Project Complexity Frontier

This experiment measures the minimum useful architecture for generated-original Python project families. It is research infrastructure, not a second CGNK planner, runtime, state authority, or delivery path.

The four preregistered conditions use the same qualified DeepSeek cheap route, prompt foundation, structured FileBundle contract, deterministic evaluator, tools, call budget, and isolated workspace:

- `B0_DIRECT_CHEAP`: current public task plus current filesystem.
- `B1_DIRECT_CHEAP_FLAT_STATE`: B0 plus a bounded flat history summary.
- `B2_MINIMAL_CGNK`: existing versioned state/evidence/recovery primitives through a thin evaluation adapter; no Blueprint, CapabilityTree, or ExecutionDAG.
- `B3_FULL_CGNK`: frozen ProjectBlueprint plus the existing CapabilityTree, ExecutionDAG, ExecutorRegistry, DAGRunner, FileRunStore, and smallest-node retry continuity.

All public and private tests derive from the same frozen family contract. Private cases are passed only to the deterministic evaluator and Project Corpus private packet. Formal generation reads no Project Corpus content.

Typical commands:

```powershell
python scripts/run_release_060.py preflight --artifact-root F:\CGKN-ITER-060 --api-lab-root D:\CGKN\.api_lab_worktree\frozen-7c15
python scripts/run_release_060.py development --artifact-root F:\CGKN-ITER-060 --api-lab-root D:\CGKN\.api_lab_worktree\frozen-7c15
python scripts/run_release_060.py formal --artifact-root F:\CGKN-ITER-060 --api-lab-root D:\CGKN\.api_lab_worktree\frozen-7c15
python scripts/run_release_060.py resume --artifact-root F:\CGKN-ITER-060 --api-lab-root D:\CGKN\.api_lab_worktree\frozen-7c15
```

The artifact root and complete Project Corpus remain local-only. Release artifacts contain aggregate results, family IDs, hashes, and sanitized metadata only.
