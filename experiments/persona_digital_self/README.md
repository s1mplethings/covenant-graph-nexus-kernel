# Persona Digital Self v1 evaluation

This experiment evaluates a transparent CGKN project persona, not a simulated
human. Project Knowledge, Promotion claims, Community policy, external-write
approval, CapabilityRegistry, Runtime, and Project State remain their existing
authorities.

The frozen deterministic benchmark has 100 meaningful episodes across twelve
recurring public identities, six communities, four platforms, and twelve
behavior categories. It compares the same inputs and rubric for:

- P0: stateless Community Operator;
- P1: Identity Constitution only;
- P2: identity plus episode, relationship, and commitment continuity;
- P3: full Persona with sparse reflection, goals, situation, attention, and
  localized action context.

The social sandbox is synthetic advisory evidence only. It cannot update real
relationships or Knowledge, authorize publication, or replace human review.
`community-read` performs bounded public reads and never writes externally.
Formal evidence must bind a clean Source Closure.
