# Customer Goal Brief

Raw customer goal: I want a local-first media production and review workbench for individual creators or small teams. It can import video, audio, and asset files, organize a material library, define a processing workflow, generate clip or item analysis, flag candidate content worth reviewing, choose outputs, export a project package, and generate a processing report. It cannot depend on cloud services and must not pretend to have real AI models. CGKN should decide the real requirement, MVP scope, non-goals, acceptance criteria, and generate a runnable local project.

CGKN interpretation: A local-first media workflow that turns raw files into traceable review/export artifacts.

Key uncertainties:
- Exact user role and daily workflow may need confirmation.
- Runtime platform and dependency constraints may need confirmation.
- Whether external services are allowed is not assumed.

Known constraints:
- Requirement decision must precede implementation.
- Delivery success still requires evidence, not only a decision summary.

Do not directly assume:
- That a static demo is enough.
- That cloud APIs or live models are available.
- That generated code can pass without requirement alignment.

CGKN autonomous decisions needed:
- Choose the best first product requirement.
- Freeze MVP scope, non-goals, and acceptance criteria.
