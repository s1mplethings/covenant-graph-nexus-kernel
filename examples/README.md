# CGKN examples

Examples are small, human-readable, and reproducible. They do not contain live
project memory, Provider responses, checkpoints, caches, generated project
copies, or raw run output.

- `artifact-driven/todo-refactor/` demonstrates typed artifact feed-forward and
  incremental recompute.
- `project-generation/knowledge/` contains compact knowledge/context examples.
- `minimal/boundary/` contains a minimal boundary-intent fixture.

Runtime output belongs under ignored `runs/`, `artifacts/`, or `generated/`
directories. Long-lived claims must be promoted into a curated `evidence/`
bundle.
