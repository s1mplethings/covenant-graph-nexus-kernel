# CGKN Codex Edition

- Product edition: `CGKN Codex Edition`
- Git branch: `codex/cgkn-codex-edition`
- Formal kernel/schema namespace: `CGKN`
- User interface: the active Codex task only
- Conversation orchestration: `scripts/codex_conversation.py` (import-only)
- Shared state: `whiteboard` and `agent_session`
- Delivery exit: `scripts/local_packager.py`

This edition requires no separate customer-service process or conversation
credential. Codex operates directly in the repository and returns customer-safe
text and approved local artifact links in the same task.

The edition name creates no Provider author, evidence authority, packager, or
delivery path. Project generation continues through the registered Provider
route and all canonical gates.
